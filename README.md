# Gaspware.dev

We build [Sneeze](https://github.com/Gaspware-dev/sneeze), a drop-in flatfile CMS for sites that stay plain HTML.

Copy one PHP folder into any website. Design templates and blocks in the studio. Publish self-contained pages visitors can open with nothing running behind them.

[gaspware.dev](https://gaspware.dev) · [Sneeze on GitHub](https://github.com/Gaspware-dev/sneeze)

## Sneeze

Sneeze lives in a subfolder next to your site and never takes over serving. Drafts stay in SQLite. Publish writes one ordinary HTML file per page, with CSS and JavaScript inlined. Delete the `sneeze/` folder and the last published pages remain.

PHP 8.2+, PDO SQLite, and a writable folder.
